# NorthPeak Digital

A modern web development studio website built with React and Tailwind CSS.

NorthPeak helps businesses create fast, responsive, and user-friendly digital experiences.

## 🚀 Features

- Responsive design for mobile, tablet, and desktop
- Modern UI with Tailwind CSS
- Smooth animations using Framer Motion
- SEO optimized structure
- Lighthouse performance optimization
- Service and pricing sections
- Client testimonials
- Contact form section

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript (ES6+)

## 📂 Sections

- Hero Section
- Services
- Pricing Plans
- Work Process
- Testimonials
- Contact
- Footer
